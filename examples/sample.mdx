# MDX terminal preview

Use `j` and `k` to scroll, `gg` and `G` to jump, `/` to search, and `q` to quit.
Press Tab to select a component and Enter to activate it.

<Callout title="Welcome">
Markdown and common MDX components can be read directly in the terminal.
</Callout>

## Tabs

<Tabs>
<TabItem label="Go">
```go
fmt.Println("Hello, MDX!")
```
</TabItem>
<TabItem label="JavaScript">
```js
console.log('Hello, MDX!')
```
</TabItem>
</Tabs>

## More

<Accordion title="Keyboard shortcuts">
Use `Ctrl-d` and `Ctrl-u` for half-page scrolling, and `n` / `N` to repeat a search.
</Accordion>
